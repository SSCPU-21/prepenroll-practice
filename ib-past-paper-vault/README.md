# IB Physics Past Paper Vault

A metadata-only index for locating IB Physics past-paper questions by current syllabus topic.

## Privacy model
- No IB question text or PDF files are stored in this repository.
- Baseline data may be added to `data.js` only when it is safe to expose publicly.
- Personal question references created in the UI are stored in browser `localStorage` only.
- Use **Export JSON** regularly for backup, and **Import JSON** to restore on another browser.

## Index fields
Year, session, SL/HL, paper, question/subpart, current A.1–E.5 topic, marks, type, difficulty, old-syllabus label, paper URL, markscheme URL, notes.

## Recommended indexing rule
Tag at the **subpart level** when a question spans multiple topics. Do not paste copyrighted question wording into notes.

Source catalog used for paper discovery: https://ibdocs.re/past-papers-by-subject/physics
